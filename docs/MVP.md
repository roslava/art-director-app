# Art Director MVP

## Workflow

1. Create or select a project and subject.
2. Capture factual research and visual risks.
3. Form an art direction and a shot plan.
4. Define individual shots with a production-ready prompt and visual constraints.
5. Later, send shots to an image-generation provider.
6. Review each asset against factual and creative criteria, then revise as needed.
7. Prepare approved assets for an export target.

This initial version delivers the workspace shell, a mock Samotsvety project, a Chrysoberyl subject summary, and a readable shot plan. It establishes the schemas that future workflow screens will use.

## Explicitly out of scope

- Real OpenAI or image-generation calls
- API routes, background jobs, queues, or webhooks
- Database persistence and migrations
- Authentication, teams, permissions, or sharing
- Uploading, storing, editing, or exporting image files
- Full research sourcing tools and automated fact verification
- Asset comparison, approval actions, and revision history UI
- Billing, analytics, and production deployment infrastructure
